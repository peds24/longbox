Longbox is a personal comic-reading tracker for Android and iOS. Scan a barcode or search by title, and it tracks what you're currently reading — pulling real issue data (cover, release date, issue number) from a live comic database instead of a spreadsheet you forget to update.

What it does

01

Add a comic three ways

Scan a barcode (UPC for single issues, ISBN for trade paperbacks), enter a code manually, or search by title. Every path lands on a confirm screen before anything's saved.

02

Current Reading

Every active series and issue at a glance — cover, title, author, release date, issue number.

03

Mark as Read

Checks the API for a real next issue first. Found one? You're asked whether to add it to Current Reading. Either way, the current issue moves to Comics Read.

04

Comics Read

Full history with search, three sort modes (Recent, A–Z, a collapsible By Series grouping), and a Check for Next Issue button on every issue.

How it's built

Expo + Expo RouterFile-based routing, TypeScript, single codebase for Android and iOS.
expo-sqliteOne tracked_comics table, a thin repository module for all reads/writes.
MetronSeries search, issue detail, and UPC-based barcode resolution for single issues.
OpenLibraryISBN lookup for trade paperbacks — no API key required.
expo-cameraCameraView targeting ean13/ean8/upc_a/upc_e symbologies.

Get started

$ npm install $ cp .env.example .env # fill in EXPO_PUBLIC_METRON_USERNAME / EXPO_PUBLIC_METRON_PASSWORD $ npm run check-apis # optional: verify Metron/OpenLibrary credentials first $ npx expo start

Requires a free Metron account for the two EXPO_PUBLIC_METRON_* variables. OpenLibrary needs no credentials. Barcode scanning needs a physical device with a camera — the simulator/emulator can exercise every other flow (search, manual entry, mark as read, read history).
